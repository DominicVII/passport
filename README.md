# Passport — The American Caesar: Dominic Z. Taylor

Personal PWA: artifacts, interpretations, milestones, political compass, writing, and figures.

## Install on iPhone (Safari)
1. Open https://dominicvii.github.io/passport/
2. Tap Share → Add to Home Screen
3. Name it Passport

Data stays on your device (localStorage). Export backups from the app footer.

## Enable GitHub Pages
In the repo Settings → Pages → Source: Deploy from branch `main` / root, then save. The site will be live at the URL above within a minute.

Built as a standalone offline-capable PWA.
